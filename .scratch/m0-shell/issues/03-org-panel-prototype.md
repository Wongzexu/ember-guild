## Answer

2026-08-26 布局三形态定案（原型资产：`.scratch/m0-shell/prototype-org-panel.html`，三个变体均保留为档案）：

- **B 战报卷轴（编年史中心）= 首页形态**——M0 就实现这个（组织面板首页，顶栏 + 中央卷轴 + 右侧时间线/入口）。
- **A 经典指挥桌 = 详情页大页面形态**——M1+ 英雄/远征详情页用，M0 不实现。
- **C 极简仪表盘 = 小窗形态**——M7 Electron 桌面"摸鱼小窗"用，M0 不实现。
- 呼应 GDD §13"信息分层"：同一份数据，三种密度/层级。

**图标定案**：采用 [game-icon-pack](https://github.com/Nieobie/game-icon-pack)（CC0 公有领域、800+ 圆角统一风格 SVG、带 Icon_Catalog.json 目录）。落地方式：**本地 vendor 进 `game/`**（不依赖 CDN，兼容离线与桌面打包），每里程碑按需取图标（用目录 JSON 检索），M0 只取组织面板所需十几个。
