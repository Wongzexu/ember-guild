## Answer

2026-08-30 解决（grilling 拍板，用户修正关键命名口径 + 采纳推荐）。产出：掉落管线蓝图章节。

**先决澄清（修正 #02 错误隐喻）：基底名固定，稀有度只加修饰词、不换基底。**
- `铜锤` = 一个基底类型（固定名 + 固有数值）。蓝装 = **"迅捷之铜锤"**（修饰词 + 基底名），**仍是铜锤，不是铁锤**。
- `铁锤`/`钢锤` 等 = **并列的不同单手锤基底类型**（各自需等级+固有值），不是「铜锤的升级」。基底决定固有值与名；稀有度决定 Magic 修饰词，二者正交。白铁锤=普通铁锤基底，蓝铁锤=附词缀铁锤基底。

**已定：**

- **① 掉落率 = 每击杀 roll 一次**，掉率 = 每区域 `baseDropRate`，首区雾林=40%（平均 2.5 杀一掉）。掉落率与品质权重是**两个独立 roll**（先掉不掉，掉再定品质）。§6 品质权重（60/32/7.5/0.5）是「掉出来的东西各品质占比」，非掉落率本身。
- **② 基底选择**：按区域 iLv 段从**可掉落基底池**抽一个基底类型（雾林 iLv1-15 = 铜锤等需1级基底；未来需5级铁锤等同区间进池）；**基底抽选与品质独立**——不随品质线性升级。
- **③ 品质 roll 次序**：先 roll 品质（白/蓝；黄/传 M3）再按品质定词缀数（白=0，蓝=1~2），从 #01 的 weapon/shield 词缀池抽。**稀有度 roll 与词缀 roll 分两个 rng 调用**，不混成一个。
- **④ 词缀防重复（用户定：取最优）**：蓝装 roll 1~2 条；抽中**同 affix 键**时不用 §5.2 前后缀分区，**重复则取更优那条数值并去重**——例：roll 到 2 条 attack_speed_pct，留值更大那条。（§5.2 前后缀标注保留备 M3，M2 蓝装不强制一前一后。）
- **⑤ rng 序列整合（判定顺序）**：击杀结算内 `gold roll → 掉落判定 roll →（品质 roll → 基底 roll → 词缀 roll）→ spawn 新怪`，全程共用一条 `meta.rngState`——rng 消耗次序固定、可复现（#12 契约在每步出手内不破）。
- **⑥ 交付形态 = 背包手动穿**：掉落只负责「生成实例 + 入背包 + 编年史提示」；玩家在非战斗态面板（#05）手动穿/换。**不做自动穿最优**（会与 #02 Q4「仅非战斗态可换装」冲突，且提前写死"最优"逻辑）。
- **⑦ 掉宝率词缀（+掉宝率%）M2 不接**（丢 M3；§5.3 防具池才有，且 M2 不穿防具）。

**命名形态（#01 数据模型的补充说明）**：实例名 = `修饰词 + 基底名`；基底名固定独立，稀有度不换基底。存档/背包/装备位只需认 `baseId`（唯一基底标识），修饰词由 `affixes[]` 派生。

**挂钩**：#01（基底数据形态，名词不换基底）、#02（攻速公式已供；掉落实例走 B 层叠入背包）、#03（击杀结算插入掉落 roll 于 spawn 前）、#05（背包/手穿交互）。
