Type: prototype
Status: resolved
Blocked by: 01, 02, 03, 04

## Question

「英雄变强可见」的 UI 呈现：装备面板长什么样、穿戴交互怎么做，让 8 槽 + 战力变化的数字显示在玩家眼前。

要答清的：

- **面板形态**：A 指挥桌详情页（M1 已做详情 A 形态）——装备面板是详情页的一个区块，还是独立页面？8 槽怎么摆（圆形属性盘？网格？列表？）？只有 2 槽可穿（主/副），其余 6 槽禁用态怎么显示。
- **战力变化展示**：穿装备前后，攻击/攻速/命中/减伤数字变化——直接改数字，还是绿/红对比闪烁？有无"战力 DPS"汇总数字（#03 攻速票问过 DPS 呈现，与此呼应）。
- **穿戴交互**：背包列表 → 点某装备 → 穿到匹配槽？已穿装备点了换装（卸下旧的回背包）？不能穿的（需等级/槽位不匹配）点上去给什么反馈。
- **背包 UI**：掉落的装备进背包列表怎么显示（卡片？图标 + 稀有度颜色？白/蓝徽记），背包与装备面板是同屏还是分屏？
- **icon**：M0 已 vendor game-icon-pack（MW）——装备图标挑哪些（武器/护甲/饰品）？

## Answer

2026-08-30 解决（prototype UI 多轮 + 拍板）。产出：`game/src/ui/proto/EquipPanelProto.vue`（挂 `?equipproto=1`）+ 本节蓝图。**选定版 = B 圆环骨架 + C 对比交互。**

**UI 定稿（装备信息呈现分层）：**

- **① 信息分层（化解「详情页 vs 装备页」数据重复）**：详情页「装备栏信息」区块 = **只读摘要表格**，只列「哪槽穿啥」（槽位 + 装备名 + 稀有度）；**不**展示攻击/护甲/DPS 等战斗数字。完整战斗数字（攻击区间/攻速/护甲减伤/DPS/命中攻击值）只出现在**装备页**。→ 同一信息的两种深度（盘点 vs 深调+对比），不是重复兜底。
- **② 装备页归属 = 背包的一个 tab**：背包页 =「装备」+「其他」tab；装备 tab 放 B+C 圆环交互页（穿脱/对比/稀有度/命名）。候选区 = 背包物品，与 #01 B 层叠「穿走即移」同源（装备在背包与英雄装备位间迁移）。PoE 结构：人物装备栏与背包同屏。
- **③ 入口**：详情页装备区块**右上角「穿戴装备」按钮** → 跳到 **背包·装备 tab**（独立视图切换）。详情页保持轻、装备集中管理。
- **④ 圆环槽位排布（定稿）**：头顶 / 脚底 / 主手最左 / 副手最右；**身体、颈链（身/颈）对调后**：头顶(0°) → 颈(45°) → 副手(90°) → 手(135°) → 脚底(180°) → 戒(225°) → 主手(270°) → 身(315°)。四锚点（头/脚/主手/副手）固定。
- **⑤ 对比交互（C 型）**：左「已穿戴」/ 右「候选中」；点候选名选中 → 下方「当前 ⟶ 更换」对比框，**提升标注放名称后面**（例：`攻击区间 6–11 (+5~+8)`）→ 点「穿上」成交。
- **⑥ 数据流接入次序（拍板：先摆位置后接真数据）**：先行步骤 = 把装备栏摘要表格（详情页）+ 背包·装备 tab（B+C 圆环）摆好、用 **stub 假数据**，原五维/战斗/天赋布局不动。后续再把 #01~#04 的引擎接线接进（hero.equipment、heroStats 折装备、heroAttackRange/AttackSpeed/armorReduction、掉落管线）。

**沿用**：DPS 汇总归面板（#03）、稀有度徽记、#04 命名（迅捷之铜锤）、#02 仅非战斗态可换装。

**原型**：`game/src/ui/proto/EquipPanelProto.vue`（已实现选定版 + 身颈对调；挂入 `App.vue` `?equipproto=1`，正式版在背包·装备 tab 复用其纯逻辑模块）。
