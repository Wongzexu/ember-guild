# 《挂机远征》概念雏形（CONCEPT）

> ✅ **规划期档案**（2026-08-26 方向定稿，PLAN 8 步全部完成）。本文保留概念推导过程作历史参照；**现行设计以 [GDD.md](GDD.md) 为准**，冲突处以 GDD 与 `docs/DECISIONS.md` 为准。

## 1. 一句话概念

> **一款架空奇幻史诗题材的放置游戏:你经营"余烬公会"这个英雄集结组织,招募各路英雄、派遣挂机远征、打造专属装备,让组织从无名小团成长为被世界记住、写入编年史的传说。**

## 2. 世界（第 2 步成果 + 第 8 步定案）

- **题材**：Duelyst 远古文明崩塌后的架空奇幻世界，**表层 = 灰烬纪元 · 幕后 = 失落的远古世界**。
- **基调**：史诗大气——文明兴衰、上古秘密、强敌环伺；文案有分量感（可带少量幽默调剂）。
- **世界名**：雅尔多拉（Aerdora）；**组织名**：余烬公会（Tinder Guild）。
- **表层历史**：远古世界在星辰/虚空灾变中崩塌；经过数千年的断代与灰烬之潮，文明、语言和血脉都发生变异，现世幸存者只能在遗迹、卡牌、武器和怪物身上辨认旧时代。
- **幕后真相**：所谓神话其实是远古世界的真实历史；六方文明、Monolith、星辰力量与虚空势力留下的断裂线索，正随着世界复苏逐步重新显形。
- **核心冲突**：重建灾后秩序 vs 找回远古世界真相；远征既是收集资源，也是把 Duelyst 远古史重新拼回编年史。
- **第一阶段选材**：优先从 Duelyst 中立单位中挑选敌人和新同伴，保持现世身份模糊，让玩家先认识“正在发生的事”，再逐步追溯它们的远古来源。
- **第一阶段叙事节奏**：从炉镇、余烬公会和远征前的平静生活开始；小规模异常逐渐扩大为敌人、遗迹和记忆回响，最终显露世界正在一步步回归远古纪元。
- **地图总纲**：Duelyst 的六个远古阵营分别对应六个大型阶段；每个大阶段再拆成多个按等级和怪物逐步推进的小区域，恢复该阵营的生态、遗迹与历史。中立单位承担第一大阶段的序章内容，也可作为跨阶段的野外生物与过渡素材。

## 3. 主角形态（第 2 步成果）

- 经营**一方势力:英雄集结组织**(类似佣兵公会,但本质是一个"英雄阵容/收藏")。
- 玩家不是单个武打,而是**组织的决策者**:招谁、养谁、派谁去干什么、给谁穿什么。
- 英雄是独立单位：各有**职业（属性成长曲线）**、等级、成长与图鉴条目（无稀有度——稀有度只属装备，v0.3）。

## 5. 属于自己的核心循环（第 3 步成果）

> 用"我们的话"画,不再抄梅尔沃的"采→造→打"个人循环:

```
        ┌────────────────────────────────────────────┐
        │  招募英雄（酒馆/线索/高难委托）→ 组建队伍      │
        │        ↓                                    │
        │  派遣出征（挂机：远征 / 采集 / 委托）          │
        │        ↓                                    │
        │  收获：金币·材料·装备·英雄线索·图鉴进度       │
        │        ↓                                    │
        │  投资回自身：                              │
        │     · 培养英雄（升级/突破/转职）              │
        │     · 打造装备（PoE 词缀锻造）               │
        │     · 升级组织（设施/科技/解锁新区域）         │
        │        ↓                                    │
        │  更强的队伍 → 更高难远征/新区域               │
        │        ↓                                    │
        └── 更好掉落 → 传奇英雄 / 传说装备 / 新图鉴 ←──┘
```

**一句话总结循环**:招英雄 → 派出去 → 拿回来 → 投进去 → 更强 → 派去更远。

## 6. 与参考作的差异（第 4 步前的中期盘点）

> 参考作盘点已扩展到 4 款：梅尔沃放置 / 最强蜗牛 / **巴尔的遗产（Loot of Baal，新增）** / 流放之路（装备）。

| 对比 | 梅尔沃 | 蜗牛 | 巴尔的遗产 | 流放之路 | **我们（雏形）** |
|------|--------|------|-----------|----------|-----------------|
| 主角 | 单人角色 | 个人养成 | 三人佣兵小队刷宝 | 单人通关 | **英雄集结组织** |
| 成长 | 个人技能 | 本体养成 | 小队+装备 | 角色+装备 | **组织+英雄双轨** |
| 收集 | 图鉴次要 | 收集驱动 | 佣兵品质/词缀 | 装备追求 | **英雄/生物/装备图鉴驱动** |
| 装备 | 简单词缀 | — | D2式词缀+打孔符文+交易 | **词缀+通货（最深）** | **PoE 式词缀+通货+铸造台保底** |
| 挂机形态 | 页游式 | 手游式 | **桌面侧栏"摸鱼"挂机** | 无 | **浏览器→桌面小窗，英雄派遣** |
| 叙事 | 弱 | 搞笑道具 | 弱 | 主线 | **活世界·编年史（钩子）** |

### 新参考：《巴尔的遗产》Loot of Baal（桌面侧栏放置刷宝 · 2025-06-16 · Gleamer Studio）

- **是什么**：运行在**电脑桌面侧边**的放置刷宝游戏（"摸鱼"神器）——你一边做其他事，游戏在桌面一角运转，**自动战斗、自动刷宝**，用挂机玩法复刻《暗黑破坏神2》的核心刷装体验。
- **核心机制**：
  - **小队**：最多 3 人佣兵小队，职业有法师/圣骑士/游侠/狂战士/死灵法师等；佣兵有 **D/C/B/A/S 品质**之分，品质越高属性越好。
  - **装备**：**上千种随机词缀**组合；可打造 200+ 装备；支持**打孔镶嵌符文**；并有**线上装备交易**。
  - **循环**：刷装备 → 变强 → 刷更高级图。
- **玩家反馈**：赞"完美复刻 D2 刷装乐趣""降维打击"；**吐槽：随机性过高，可能长期挂机无提升；初期开荒难**。
- **对我们方案的印证**：① "佣兵团外出探索收战利品"与我们的 S3 英雄派遣挂机**同源**；② 挂机+刷宝+交易组合被市场验证可行；③ "桌面一角跑挂机"恰好支撑"浏览器→桌面程序"设想——**小窗/侧栏形态契合**；④ 多职业英雄编队+品质档位，支持我们的 S2 英雄系统。
- **我们的差异点（它没有的）**：英雄个体性格与自主行动、活世界大事件、编年史史诗记录——它更偏"刷宝生产机器"，我们更偏**"有记忆、有历史的组织"**。

### 6.1 从《巴尔的遗产》学到的教训（重要）

| 它的坑 | 我们的对策（已有/待做） |
|--------|----------------------|
| 纯随机、长期挂机无提升 → 玩家流失 | 铸造台**确定性锻造**保底（已规划）；后续加"词缀保底/降级保护"，让投入始终有回报 |
| 初期开荒困难劝退 | "前期快节奏"已定案：首 1 小时频繁正反馈 |
| 纯刷装无叙事，挂久了空虚 | 我们的「活世界·编年史」钩子正是补这块 |
| 线上交易需服务端，复杂 | 我们**无后端起步**；交易列为未来可选项、不绑死 |

> 结论：巴尔的遗产用"极致摸鱼"证明了刷宝挂机成立；**我们的差异化不在"更会刷"，而在"组织的厚度 + 世界会记住你"**——这是它没有的维度。

### 7.4 英雄系统设计要点（第 5 步细化 ✅）

> 已确认（v0.3 修订 2026-08-26）：**职业成长曲线** + **自动加点（带策略倾向）** + **等级解锁天赋词条**；英雄取消稀有度（稀有度只属装备）。吸收"自动连续刷图"手感。

- **职业**：
  - 每个英雄 = 名字 + 职业 + 等级。**职业决定属性成长曲线**（偏攻职业 STR 成长高 / 偏防职业 VIT 高…）——与属性值挂钩，保留软职业"不锁死玩法"的影子。
  - **实际流派由装备定型**：拿近战武器（单手锤/大锤/短刀/大剑/矛/匕首）→物理近战向，拿法术武器（短杖/长杖/法器）→施法向，拿弓弩→远程速攻向。换装备即换定位（PoE 式自由）。
- **等级与天赋**：等级上限 100（正常），特殊途径可超；成长曲线 RS（前期快后期慢）。**天赋 = Torchlight 式被动词条**——随等级达标自动解锁（示例：艾格雷姆 Lv.5 STR+5，细则 NUMBERS §3.3），无需手动加点。
- **属性成长**：STR/DEX/VIT/INT/AGI（五维，NUMBERS §3.1）随等级**自动加点**；职业曲线为基准，玩家**策略倾向**（偏攻/偏肉/偏速/偏智/均衡）做权重微调，不费脑、适合挂机。
- **稀有度（英雄无）**：英雄**不设稀有度**——稀有度只属于装备（PoE 原生形态）；英雄间差异 = 职业曲线 + 天赋词条 + 装备 + 获取初始等级。装备稀有度沿用 普通/稀有/史诗/传说 命名（巴尔的遗产 D/C/B/A/S 档位仍不借鉴）。
- **身份差异化**：英雄还各有**性格/口头禅/背景故事**，为「离线自主行动」和「编年史」提供叙事素材。
- **借鉴点**：S3 出征采用**自动连续刷图**手感（点一下开始，自动连刷当前图直到手动停/资源不足）。
