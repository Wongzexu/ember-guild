## 0. 这份文档怎么读

游戏 = **一个循环 + 一堆规则**。挂机游戏 = **让循环自己转**，玩家回来"收菜"、做决策、看成长。本文档用大白话写，术语不懂随时问我。

**一句话游戏**：架空奇幻史诗世界，你经营一个**英雄集结组织**——招英雄、派远征、打造词缀神装，让组织从无名小团成长为被世界记住、写入编年史的传说。

**设计原则（2026-08-27）**：多数系统**跨游戏取经**——从别的游戏里"借结构、换包装"：PoE（六职业分布/装备词缀）、Diablo 2（VIT 体力侧）、Dota 卡尔 Invoker（三元素球+配比组合）、Torchlight（等级解锁天赋）。借鉴时先问"这个结构为什么好"，再决定拿不拿。**文档内具体数值一律视为暂定草案**，结构是基准、数字后续调。

## 1. 核心循环（本作之魂）

```
招募英雄（酒馆/线索/高难委托）→ 组建队伍
      ↓ 派遣出征（挂机：远征 / 采集 / 委托，自动连刷）
收获：金币·材料·装备·英雄线索·图鉴进度 · 编年史事迹
      ↓ 投资回自身
培养英雄（升级/突破）· 打造装备（PoE 词缀）· 升级组织（设施/科技/新区域）
      ↓
更强的队伍 → 更高难远征/世界事件 → 更好掉落 → 传奇英雄/传说装备/新图鉴
```

**一句话：招英雄 → 派出去 → 拿回来 → 投进去 → 更强 → 派去更远。**

## 2. 名词速查

| 词 | 意思 |
|----|------|
| 组织 | 你经营的一方势力（英雄集结组织），有等级/设施/科技/传奇度 |
| 英雄 | 组织的单位，有天生倾向/稀有度/等级/性格，独立成长 |
| 天生倾向 | 英雄与生俱来的偏向（偏攻/防/速/智），是身份与图鉴钩子，不锁死玩法 |
| 装备定型 | 实际流派由装备决定：拿大剑=物理向，拿法杖=施法向（换装即换定位） |
| 远征/出征 | 派英雄出去的挂机活动（副本刷图/采集/委托），自动连刷 |
| 词缀 | 装备上随机出现的属性加成（前缀/后缀分池） |
| 通货 | 锻造装备的消耗品（各种"石"） |
| 编年史 | 世界记录组织一切事迹的史诗书；组织传奇度≈世界对你的态度 |
| 世界事件 | 世界定期抛给组织的挑战（巨兽攻城/裂隙/敌团），需决策应对 |
| 图鉴 | 英雄/生物/装备的收藏册，收集驱动长线目标 |
| 离线收益 | 关游戏后按时间补发的产出（离线时英雄按性格自主行动） |

## 3. 世界观设定（已选候选 A + B 幕后）

- **题材**：架空奇幻世界（非现实中世纪），**表层 = 灰烬纪元 · 幕后 = 星辰纪**（A 世界观打底，B 当作隐藏真相）。
- **基调**：史诗大气——文明兴衰、上古秘密、强敌环伺；文案有分量，可带少量幽默调剂。
- **世界名**：雅尔多拉（Aerdora）
- **组织名**：余烬公会（Tinder Guild）
- **表层历史（编年史第一卷）**：吞没旧文明的「灰烬之潮」退去百年，幸存据点重新拼接世界；组织使命是找回失落英雄的遗骸与秘宝——**编年史 = 重写历史**。
- **幕后真相（编年史埋的线）**：传说中古神陨落、星辰坠入大地——**灰烬之潮的真正起源是"星辰之灾"**；星核与异变生物潜伏在灰烬之下，随组织传奇度升高逐渐浮现。
- **核心冲突**：重建旧世界秩序 vs 侦破星辰真相（表层给短期目标，幕后给长期悬念）。
- **可后置**：地理雏形、种族细节（写数据表时再补）。

## 5. 英雄系统（S2）

> v0.3 修订（2026-08-26）：英雄取消稀有度（只留装备稀有度），改为**等级体系**；软职业改版为**职业成长曲线**；新增**等级解锁天赋词条**。
> v0.4 修订（2026-08-27）：职业表定稿（12 职业 = 六核 × 近/远家族）、五维属性（+AGI 闪避）、家族轴显性、天赋挂武器家族条件、元素三档台账（详见 DECISIONS / NUMBERS §3、§4.4）。

- **英雄构成**：名字 + 职业 + 等级 + 性格/背景。没有稀有度——**稀有度只属于装备**（PoE 原生形态）。
- **等级**：上限 **100**（正常途径），特殊途径可突破 100；成长曲线保留（RS：前期快、后期慢）。获取时的初始等级/状态差异（如高难委托加入的英雄起点更高）承担原"稀有度"的语义——差异在**起跑线**，不在天花板；**所有英雄都可无限成长**。
- **职业**：12 职业（**六核 × 近/远武器家族**，NUMBERS §3.4）——决定**属性成长曲线 + 元素主色 + 武器条件天赋**；同一核的近/远职业共享成长，差异在家族轴（近战 VIT / 远程 AGI）与天赋。
- **家族轴（显性）**：近战职业 VIT 额外成长、远程职业 AGI 额外成长——面板可见、职业描述点明（"家族倾向：坚实体魄 / 灵巧身法"）。
- **装备定型**：实际流派由装备武器决定（大剑→物理向 / 法杖→施法向 / 弓→远程速攻向）；**换装备即换定位**（PoE 式自由，保留）；天赋对武器家族取条件，跨族换装只弱化不报废。
- **属性**：STR/DEX/VIT/INT/**AGI**（五维，NUMBERS §3.1）；职业曲线 + 家族轴为基准，玩家策略倾向（偏攻/偏肉/偏速/偏智/均衡）做权重微调——不费脑，适合挂机。
- **天赋（被动词条）**：Torchlight 式——随**等级达标解锁词条**（例：Lv.5 "攻速 +5%"、Lv.10 "对应元素伤害 +10%"…），自动生效的被动加成，无需手动加点；词条条件 = 近/远武器家族 + 通用垫底（NUMBERS §3.3/§3.4）。
- **性格与背景**：每个英雄有性格/口头禅/背景故事 → 喂给「离线自主行动」和「编年史」，让英雄是"人"不是"数值"（保留）。
- **招募**：酒馆招募（消耗金币/线索）、远征掉落线索、高难委托慕名加入（保留）。

## 6. 出征与挂机（S3）

- **派遣**：选择区域→派出队伍→**自动连续刷图**（点一下开始，自动打到手动停/资源不足为止）——吸收自《巴尔的遗产》的极简手感。
- **产出**：金币、材料、装备（含词缀）、英雄线索、图鉴进度、编年史事迹。
- **并行**：可同时派多支队伍去不同活动（出征 + 采集 + 委托），玩家当调度者。
- **离线**：关游戏后英雄按各自性格进行**自主行动**（有人去探险、有人修炼、有人喝酒），回来汇报事件并带回产出（详见第 10 章）。

## 7. 装备系统（S4 · PoE 式，已简化）

沿用已定稿的 PoE 简化方案（前缀/后缀/词缀 Tier/稀有度/通货/铸造台）：

- **基底**：按类型（剑/弓/法杖/头盔/胸甲…)分级，自带基础属性和**隐含词缀**。
- **稀有度**：普通(白)→魔法(蓝)→稀有(黄)→传奇(暗金)，决定词缀数上限（0/1-2/3-6/固定）。
- **词缀**：最多 3 前+3 后；每个词缀有 **Tier（档位）** 与数值区间；**物品等级 iLv 决定能出的最高 Tier**（高级怪掉高级装，驱动爬图）。
- **通货锻造**：蜕变石/点金石/改造石/重铸石/混沌石/崇高石/神圣石（掉率见 NUMBERS）。
- **铸造台保底**：消耗固定资源**必定**上指定词缀——对冲脸黑，回应巴尔的遗产"纯随机劝退"教训。
- **已简化不做**（初期）：连线、技能宝石、打孔符文（灵珠列为后期可选）。

## 8. 组织系统（S1）

- **组织等级**：总经验来自"成员产出+远征完成+事迹"，驱动全局解锁。
- **设施**：酒馆（招人）、铸造台（锻造）、仓库（容量上限）、编年史馆（解锁记录/加成）等，逐步解锁。
- **科技树**：全局被动（+产出%/掉宝%/经验%），消耗资源研究——给资源一个稳定出口。
- **传奇度**：由编年史事迹累积，影响世界对你的回应（更高端委托、隐藏事件、NPC 态度）。

---

## 9. 世界与编年史（S5 · 主打钩子「活世界·编年史」）

**钩子三件套：世界有脾气 · 英雄有生活 · 记忆被记录**

1. **编年史（记录）**：每次远征、胜败、英雄功勋、组织里程碑都写入编年史（带时间/地点/英雄名字的叙事条目）。这是游戏"记住你"的方式。
2. **世界事件（脾气）**：定期随机/定时抛出大事件（巨兽攻城、异界裂隙、敌团袭击、上古遗迹出土），必须决策派谁应战；成败写进编年史并影响传奇度。
3. **离线自主行动（生活）**：离线时英雄按性格自主行动，回来汇报"我干了什么"——把挂机变成"收获一段人生"。

**世界回应**：传奇度越高，世界给你更高端的委托、隐藏事件、传奇级招募线索——组织的故事越精彩，世界越愿意向你开放。

## 10. 挂机与离线收益（通用框架）

- **在线**：Tick 推进（1 Tick=0.5 秒），多队伍并行挂机。
- **离线结算**：`有效产出 = 离线时长 × 每秒产出 × 离线效率系数(默认60%)`，单次结算上限 24 小时，防数值爆炸；离线期间叠加"英雄自主行动"叙事事件（只产出少量额外奖励+有趣汇报，不膨胀数值）。
- **前期快、后期慢**：经验曲线 RS 式（见 NUMBERS 第 2 章），前 40 级快速正反馈，99 级厚积目标。

## 11. 图鉴系统（S6）

- **英雄图鉴**：见过的英雄/稀有度/背景解锁条目（收集驱动）。
- **生物图鉴**：每类敌人的资料随击杀次数解锁（掉落提示、弱点）。
- **装备图鉴**：见过的装备基底/词缀记录，收集词缀组合达人可炫耀。
- 图鉴进度给全局小加成，**只奖不罚**（奖励收集，不惩罚不收集）。

---

## 12. 经济（S7）

- **金币**=软通货（买卖、设施、手续费）；**材料**=生产中间物；**通货**=硬通货（锻造用，贵且稀有）。
- 金币主要来源：卖装备/远征；出口：商店、设施升级、铸造台手续费。
- **无线上交易**（无后端起步；交易列为未来可选项，不绑死）。

## 13. 界面（极简）

- 顶栏：组织信息条（等级/传奇度/金币/队伍状态）。
- 中央：当前活动面板（出征进度条、产出日志、战利品弹窗"掉了一件好东西!"）。
- 左侧：组织/英雄/远征导航；右侧：背包/装备栏/铸造台/编年史入口。
- 信息分层：新手只显示必要信息；词缀/编年史详情可展开。
- 形态：网页全窗口（初期）→ 桌面小窗/侧栏（后期，巴尔的遗产式"摸鱼"形态）。

## 14. 技术方案（详见 ARCHITECTURE.md）

- **前端**：Vue 3 + Vite（JS 起步，后期可加 TS）；**无后端起步**，预留云存档接口。
- **引擎**：纯函数 Tick 循环；状态=单一 JSON 快照；固定随机种子；版本化存档。
- **桌面化**：后期 Electron 打包，同一份代码，浏览器版→桌面小窗版。
- **节奏**：方向已定稿（2026-08-26 验收通过），进入 M0 开发（当前里程碑=空壳，见第 15 章）。
