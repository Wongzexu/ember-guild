## 0. 这份文档怎么读

游戏 = **一个循环 + 一堆规则**。挂机游戏 = **让循环自己转**，玩家回来"收菜"、做决策、看成长。本文档用大白话写，术语不懂随时问我。

**一句话游戏**：架空奇幻史诗世界，你经营一个**英雄集结组织**——招英雄、派远征、打造词缀神装，让组织从无名小团成长为被世界记住、写入编年史的传说。

**设计原则（2026-08-27）**：多数系统**跨游戏取经**——从别的游戏里"借结构、换包装"：PoE（六职业分布/装备词缀）、Diablo 2（VIT 体力侧）、Dota 卡尔 Invoker（三元素球+配比组合）、Torchlight（等级解锁天赋）。借鉴时先问"这个结构为什么好"，再决定拿不拿。**文档内具体数值一律视为暂定草案**，结构是基准、数字后续调。
**体系总纲（v0.7）**：战斗/成长类结构以**几何定位法**（圆盘/坐标）构思，规则随位置可推导——正文见 [SYSTEMS.md](SYSTEMS.md)（属性盘/元素环/两极/命闪/防御/职业落位）。

## 1. 核心循环（本作之魂）

```
招募英雄（酒馆/线索/高难委托）→ 组建队伍
      ↓ 派遣出征（挂机：远征 / 采集 / 委托，自动连刷）
收获：金币·材料·装备·英雄线索·图鉴进度 · 编年史事迹
      ↓ 投资回自身
培养英雄（升级/突破）· 打造装备（PoE 词缀）· 升级组织（设施/科技/新区域）
      ↓
更强的队伍 → 更高难远征/世界事件 → 更好掉落 → 传奇英雄/传说装备/新图鉴
```

**一句话：招英雄 → 派出去 → 拿回来 → 投进去 → 更强 → 派去更远。**

## 2. 名词速查

| 词 | 意思 |
|----|------|
| 组织 | 你经营的一方势力（英雄集结组织），有等级/设施/科技/传奇度 |
| 英雄 | 组织的单位，有职业/等级/性格，独立成长（**无稀有度**——稀有度只属装备） |
| 天生倾向 | 英雄与生俱来的偏向（偏攻/防/速/智），是身份与图鉴钩子，不锁死玩法 |
| 装备定型 | 实际流派由装备决定：近战武器（大锤/短刀/大剑…）=物理近战向，法术武器（短杖/长杖/法器）=施法向，弓弩=远程速攻向（换装即换定位） |
| 远征/出征 | 派英雄出去的挂机活动（副本刷图/采集/委托），自动连刷 |
| 词缀 | 装备上随机出现的属性加成（前缀/后缀分池） |
| 通货 | 锻造装备的消耗品（各种"石"） |
| 编年史 | 世界记录组织一切事迹的史诗书；组织传奇度≈世界对你的态度 |
| 世界事件 | 世界定期抛给组织的挑战（巨兽攻城/裂隙/敌团），需决策应对 |
| 图鉴 | 英雄/生物/装备的收藏册，收集驱动长线目标 |
| 离线收益 | 关游戏后按时间补发的产出（离线时英雄按性格自主行动） |

## 3. 世界观设定（灾后远古世界）

- **题材**：Duelyst 远古文明崩塌后的架空奇幻世界；本作采用轻改写，不回避远古素材和历史原型。
- **基调**：史诗大气——文明兴衰、上古秘密、强敌环伺；文案有分量，可带少量幽默调剂。
- **世界名**：雅尔多拉（Aerdora）
- **组织名**：余烬公会（Tinder Guild）
- **表层历史（编年史第一卷）**：旧世界在星辰/虚空灾变中崩塌；数千年断代后，灰烬之潮才逐渐退去，幸存据点重新拼接世界。组织使命是找回失落英雄的遗骸、遗物和历史碎片。
- **远古历史（编年史后续卷）**：六方文明、Monolith、远古将领与虚空势力并非传说，而是被灾难掩埋的真实历史；现世通过素材原型、遗迹、卡牌和敌人逐步认出它们。
- **核心冲突**：重建灾后秩序 vs 找回远古世界真相；**编年史 = 在世界复苏过程中重新拼回旧史**。
- **第一阶段内容策略**：敌人与新同伴优先从 Duelyst 中立单位中挑选；先以现世身份登场，再通过图鉴、遗物和编年史逐步揭示远古对应关系。
- **第一阶段叙事节奏**：从平静生活切入，逐步引入异常、失控的敌人和远古遗迹；玩家会感到世界不是突然改变，而是在一点点回到原始纪元。
- **序章表现**：开局的“发现迷雾笼罩、异象环生”和艾格雷姆登场暂时以连续文字事件播放；关键节点配合角色立绘/动画和一句台词，最后以“加入战斗”进入首场战斗。
- **0-1 初始战场**：作为第一次战斗教学，初始英雄艾格雷姆只面对一只**余烬猎犬**（素材原型：Duelyst `Blaze Hound`）；不出现蓝刺蝎或 `Golden Mantella`。
- **1-1 迷雾边缘基础敌人**：**余烬猎犬**与**蓝刺蝎**（素材原型：Duelyst `Bluetip Scorpion`）并列登场，在正式首区轮流随机刷新。猎犬代表炉火异常，蓝刺蝎代表远古毒刺/魔力生物；两者是不同战斗手感，不构成强弱或阶段升级关系。
- **第一大阶段地图结构**：第一大阶段不是一个区域，而是由多个连续解锁的小区域组成；**迷雾边缘约为 Lv.1–5**，之后再进入营地、山口、废墟等区域。小区域名称和风格根据实际选入的怪物、素材与叙事调整，不提前锁死。
- **1-1 小 Boss**：**Golden Mantella**（本作暂名待定，素材原型：Duelyst `Golden Mantella`）作为迷雾边缘的首个小 Boss；它是远古生物复苏的早期集中体现，不是第一大阶段末端或最终世界级反派。
- **1-1 固定阵容**：初始英雄艾格雷姆、普通怪物余烬猎犬与蓝刺蝎、小 Boss `Golden Mantella`。
- **大阶段与阵营**：Duelyst 六个远古阵营各自对应一个大型阶段；大型阶段内部拆分为多个小区域，围绕该阵营的怪物、同伴、遗迹、素材风格和 Boss 展开。第一大阶段先以中立单位为主，作为没有明确阵营归属的灾后序章；具体阵营顺序后续根据怪物选型决定。
- **可后置**：地理雏形、种族细节（写数据表时再补）。

## 6. 出征与挂机（S3）

- **派遣**：选择区域→派出队伍→**自动连续刷图**（点一下开始，自动打到手动停/资源不足为止）——吸收自《巴尔的遗产》的极简手感。
- **产出**：金币、材料、装备（含词缀）、英雄线索、图鉴进度、编年史事迹。
- **并行**：可同时派多支队伍去不同活动（出征 + 采集 + 委托），玩家当调度者。
- **离线**：关游戏后英雄按各自性格进行**自主行动**（有人去探险、有人修炼、有人喝酒），回来汇报事件并带回产出（详见第 10 章）。

## 8. 组织系统（S1）

- **组织等级**：总经验来自"成员产出+远征完成+事迹"，驱动全局解锁。
- **设施**：酒馆（招人）、铸造台（锻造）、仓库（容量上限）、编年史馆（解锁记录/加成）等，逐步解锁。
- **科技树**：全局被动（+产出%/掉宝%/经验%），消耗资源研究——给资源一个稳定出口。
- **传奇度**：由编年史事迹累积，影响世界对你的回应（更高端委托、隐藏事件、NPC 态度）。

## 9. 世界与编年史（S5 · 主打钩子「活世界·编年史」）

**钩子三件套：世界有脾气 · 英雄有生活 · 记忆被记录**

1. **编年史（记录）**：每次远征、胜败、英雄功勋、组织里程碑都写入编年史（带时间/地点/英雄名字的叙事条目）。这是游戏"记住你"的方式。
2. **世界事件（脾气）**：定期随机/定时抛出大事件（巨兽攻城、异界裂隙、敌团袭击、上古遗迹出土），必须决策派谁应战；成败写进编年史并影响传奇度。
3. **离线自主行动（生活）**：离线时英雄按性格自主行动，回来汇报"我干了什么"——把挂机变成"收获一段人生"。

**世界回应**：传奇度越高，世界给你更高端的委托、隐藏事件、传奇级招募线索——组织的故事越精彩，世界越愿意向你开放。

## 10. 挂机与离线收益（通用框架）

- **在线**：Tick 推进（1 Tick=0.5 秒），多队伍并行挂机。
- **离线结算**：`有效产出 = 离线时长 × 每秒产出 × 离线效率系数(默认60%)`，单次结算上限 24 小时，防数值爆炸；离线期间叠加"英雄自主行动"叙事事件（只产出少量额外奖励+有趣汇报，不膨胀数值）。
- **前期快、后期慢**：经验曲线 RS 式（见 NUMBERS 第 2 章），前 40 级快速正反馈，99 级厚积目标。

## 11. 图鉴系统（S6）

- **英雄图鉴**：见过的英雄/职业/背景解锁条目（收集驱动；英雄无稀有度）。
- **生物图鉴**：每类敌人的资料随击杀次数解锁（掉落提示、弱点）。
- **装备图鉴**：见过的装备基底/词缀记录，收集词缀组合达人可炫耀。
- 图鉴进度给全局小加成，**只奖不罚**（奖励收集，不惩罚不收集）。

## 12. 经济（S7）

- **金币**=软通货（买卖、设施、手续费）；**材料**=生产中间物；**通货**=硬通货（锻造用，贵且稀有）。
- 金币主要来源：卖装备/远征；出口：商店、设施升级、铸造台手续费。
- **无线上交易**（无后端起步；交易列为未来可选项，不绑死）。

## 13. 界面（极简）

- 顶栏：组织信息条（等级/传奇度/金币/队伍状态）。
- 中央：当前活动面板（出征进度条、产出日志、战利品弹窗"掉了一件好东西!"）。
- 左侧：组织/英雄/远征导航；右侧：背包/装备栏/铸造台/编年史入口。

### 13.1 战斗血条表现

- 血条绑定战斗实体，不再作为远离角色的独立整条信息栏：英雄和敌人的血条分别显示在自身立绘/动画附近。
- 血条显示当前生命 / 最大生命；英雄使用绿色或青绿色，敌人使用暗红色，濒死时变红并轻微脉冲。
- 受伤时在角色附近显示掉血数字并让血条短暂闪烁，死亡后短暂保留再淡出，帮助玩家理解战斗结果。
- 三人队时每个英雄拥有独立的窄卡片和血条；桌面端采用左右对战布局，移动端改为上下布局。
- 数据仍直接读取 `hero.hp`、`heroStats(hero).maxHp`、`monster.hp` 和 `monster.maxHp`，只调整表现层，不改变战斗结算。
- 整体摘要血条仅作为无动画/辅助模式保留，不作为主要战斗表现。
- 攻击表现采用分层映射：英雄攻击动作 → 命中事件 → 目标受击动画 → 攻击类型对应特效 → 掉血数字；英雄攻击动作和击中特效不做一对一硬绑定。
- 第一阶段艾格雷姆使用 `attack.webm`；命中冲击 fx 按 `fx.impact` 单位绑定（见下），受击方通用受击闪光为 `fx_impactred`（备选叠加伤害印痕 `fx_damagedecal`）；治疗事件使用 `fx_heal`，未命中只显示 `MISS`，不播放命中特效。
- 命中冲击 fx 的颜色/选型跟随**攻击方的元素**（攻击本身的元素），不跟受击方：英雄攻击取武器元素（M3 元素词缀落地后接线，关联 PENDING #18），怪物攻击取 `monsters.json` 元素字段；受击方元素不参与冲击 fx 选色，未来的抗性/免疫表现另行设计，不复用冲击 fx 颜色。
- 攻击命中特效与**单位像素风格绑定**：换武器只影响属性与近战/远程标记（LoL/Dota2 式，不换模型/动画外观），因此 fx 引用直接写入 `visuals.js` 单位视觉配置（`fx.impact = { sprite, dx, dy }` 或层数组，多层同帧叠放：艾格雷姆=原版 `Sworn Defender` 专属组合 `fx_collisionblue` 蓝火花 + `fx_impact2` 白色冲击（2026-09-05 考据原版 `UnitAttackedFX` 接入）、蓝刺蝎=`fx_clawslash` 一道偏移爪痕（尾攻击，dx/dy 定落点偏移）、余烬猎犬**无专属命中特效**——扑咬动画自带爆炸吼叫演出）；fx 素材本身仍来自共享特效库（原版火花族另有绿/紫色变体可后续拉取），冲击落点锚定受击者地面、视觉中心在半身腰，偏移由配置承载。
- WebM 暂无帧级命中标记，命中时刻用每单位粗粒度 `attackHitMs` 配置（`visuals.js` timing：`attackDurationMs`/`attackHitMs`），在命中事件到达时触发表现；后续根据实际观感调整，不让动画参与结算。
