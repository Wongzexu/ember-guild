# 《挂机远征》数值参考（NUMBERS / Game Data）· v0.2

> ⚠️ **规划草案 · 非正式方向**
> 配套 GDD v0.2（英雄集结组织 + 活世界·编年史方向）。所有数字为**占位初值**，随时可调。原则：**前期快、后期慢；软上限、不崩坏。**
> v0.2 变更：删除旧"个人采集技能"表，替换为**组织/英雄/远征**体系；装备、词缀、通货表沿用（仍有效）。

- `1 Tick = 0.5 秒`，每秒 2 Tick。
- 所有动作间隔/攻击频率以 Tick 计，方便换算每秒产出。

## 3. 英雄属性成长

### 3.1 五维属性（v0.4：新增 AGI）

| 属性 | 作用 |
|------|------|
| STR 力量 | `物理伤害 = 武器伤害 × (1 + STR/100)` |
| DEX 敏捷 | 攻速、命中修正（不拆分，保持一维双用） |
| VIT 体质 | `最大HP = 100 + VIT×12` |
| INT 智力 | 元素伤害加成（配灵珠/附魔用） |
| AGI 灵巧 | 闪避率（受击闪避公式 M2 定：`闪避率 = AGI/(AGI+敌方命中)` 纲要）；远程家族轴上浮 |

> 五维 = 三核伤害轴（STR/DEX/INT）+ 生存对（VIT 生命 / AGI 闪避）。
> 家族轴（显性、只加不减）：详见 §3.2。

### 3.2 自动加点规则（v0.4：五维 + 家族轴）

- 每升 1 级：五维各 **+1**（基础）。
- 玩家设**策略倾向**：偏攻（STR）/ 偏肉（VIT）/ 偏速（DEX）/ 偏智（INT）/ 均衡——**AGI 不进倾向点**（已是远程家族的公共成长，再选就重复堆叠）。
- 每 5 级额外给 **+2** 点按倾向权重分配——简单、不费脑、又有方向感。
- **职业成长曲线**为属性加成基准（见 §3.4 职业表）：核属性额外成长，系数暂定（单核 +0.4/级、双核各 +0.3/级）。
- **家族轴（显性）**：近战家族 VIT 额外 +0.5/级、远程家族 AGI 额外 +0.5/级（暂定，100 级差约 50 点，体感"近战硬、远程滑"）；只加不减。台面呈现：面板属性数字差异 + 职业页「家族倾向：坚实体魄 / 灵巧身法」。

### 3.3 英雄等级与天赋（v0.3 修订，替代原"稀有度定上限"）

- **英雄无稀有度**——稀有度只属于装备。英雄差异 = 职业成长曲线 + 天赋词条 + 装备 + 初始等级。
- **等级**：上限 **100**（正常途径）；特殊途径（世界事件/传奇内容）可突破 100。成长曲线 RS（§2）保留，人人可达 100。
- **获取初始等级**：招募来源决定起点（酒馆常客 Lv.1 起 / 高难委托加入者 Lv.10+ 起）——原"稀有度"语义由初始等级承担。
- **天赋（被动词条，Torchlight 式）**：随等级达标自动解锁，无需手动加点。示例占位（正式表随职业表定稿）：

| 等级 | 示例词条 |
|------|---------|
| Lv.1 | （职业基础被动，如烈焰血脉：火焰伤害 +5%） |
| Lv.5 | 攻速 +5% |
| Lv.10 | 对应元素伤害 +10% |
| Lv.15 | 暴击率 +3% |
| Lv.20 | 生命 +50 |
| Lv.30+ | 职业特色词条（如无视护甲 10%） |
| Lv.50+ | 双词条档位 |
| Lv.100 | 终局词条（突破 100 的途径之一） |

> **天赋条件（v0.4）**：近战家族词条 = 持**近战武器**时生效；远程家族 = 持**远程武器**时生效；通用词条（攻速/暴击/生命…）无条件生效——"换装备即换定位"的软自由保留。元素主色见 §4.4，职业表见 §3.4。

## 4. 战斗与远征数值

### 4.1 战斗公式（小队自动对撞）

```
命中率   = 攻击力 / (攻击力 + 敌方闪避)            （5%~95% 截断）
英雄伤害 = 武器伤害区间 × (1 + STR/100) × (1 + Σ增伤%) × 命中修正
减伤     = 1 - 300/(300 + 总护甲)                  （护甲300≈减伤50%，软上限）
敌方伤害 = 敌方基础伤害 × (1 - 减伤)
```

### 4.2 队伍规模

- 已定：**最多 3 人一队**；队伍成员依次出手，共用敌方目标。
- 主力携带食物自动回血（HP<50% 自动吃），食物耗尽打不过则自动撤退回组织。

### 4.4 元素与伤害体系（v0.4 · 三档）

| 档 | 类型 | 机制待遇（暂定） |
|---|---|---|
| 常规主元素（3） | 火 / 雷 / 冰 | 走 INT 元素伤害加成；对应词缀（附加火焰点伤等，见 §5.2） |
| 特殊能力元素 | 毒 | DoT + debuff：不吃元素加成/攻速/暴击，只吃毒素相关词条；附带减速/腐蚀类效果 |
| 特殊能力元素 | 奥术 | 术法本质（法球/晶刃/光束）：吃 INT，视为"无属性法力伤"——不吃元素抗性/元素易伤，只吃法术伤害增减 |
| 基准 | 物理 | 武器基准伤害类型，护甲减伤基准线 |
| 特殊穿透 | 真实伤害 | 无视全部防御，特殊机制位（湮灭炮等） |

- 元素主色挂职业（§3.4）；初稿"火/冰/雷/物理"台账在此收敛为三元素 + 特殊能力元素 + 基准/穿透。
- 具体数字与公式（闪避率、抗性、状态持续时间）M2 战斗公式定稿时配套，此处只定分类骨架。

## 9. 离线结算（确定性公式）

```
启动时：
  离线时长 = now - lastSavedAt
  若 > 1 分钟：
    有效产出 = 离线时长 × 在线每秒产出 × 离线效率系数(60%)
    经验    = 离线时长 × 在线每秒经验 × 0.6
    单次结算上限 = 24 小时（超出丢弃）
  叠加：英雄自主行动事件 1~3 条（只给少量额外奖励+叙事汇报，防止数值爆炸）
```

- 上限保护：24h 封顶 + 击杀数/开箱数封顶，避免一次结算卡死浏览器。
- 离线 60% < 在线 100%：鼓励在线，不惩罚离线（配合"摸鱼"形态：挂着就行）。
