## 3. 英雄属性成长

### 3.1 五维属性（v0.4：新增 AGI）

| 属性 | 作用 |
|------|------|
| STR 力量 | `物理伤害 = 武器伤害 × (1 + STR/100)` |
| DEX 敏捷 | 攻速（`攻速 = BPS × (1 + DEX/100 + Σ攻速词缀%)`）+ 攻击值（`DEX×10` 入命中管线，§4.1）——不拆分，保持一维双用 |
| VIT 体质 | `最大HP = 100 + VIT×12`；出物抗/法抗（属性端减免，转出随职业落位，SYSTEMS §2.2） |
| INT 智力 | 元素伤害加成 + 法术转出（直击/特效，落位见 SYSTEMS §2.3；配灵珠/附魔用） |
| AGI 灵巧 | 闪避率（分**物理闪避/法术闪避**，转出随职业落位，见 SYSTEMS §2；受击闪避公式 M2 定：`闪避率 = AGI/(AGI+敌方命中)` 纲要）；远程家族轴上浮 |

> 五维 = 三核伤害轴（STR/DEX/INT）+ 生存对（VIT 生命+出抗 / AGI 闪避）。
> 家族轴（显性、只加不减）：详见 §3.2；VIT/AGI 转出几何规则见 SYSTEMS §2（力量直径/敏捷直径）。

### 3.2 自动加点规则（v0.4：五维 + 家族轴）

- 每升 1 级：五维各 **+1**（基础）。
- 玩家设**策略倾向**：偏攻（STR）/ 偏肉（VIT）/ 偏速（DEX）/ 偏智（INT）/ 均衡——**AGI 不进倾向点**。
- 每 5 级额外给 **+2** 点按倾向权重分配——简单、不费脑、又有方向感。

> **AGI 不入倾向池的论证（#11 讨论结论 · 取代旧"重复堆叠"说法）**：防御两条道分家——**VIT 稳轴**（确定性：HP+抗性，通用，可微调）入池；**AGI 赌轴**（随机闪避，职业专属：远程家族/落位分桶）不入池。理由：①防"稳×赌"双通道乘积防御（近战偏闪 = 倾向点买到第二条防御线，直冲 PENDING #14 三防可控性）；②赌轴收益不透明（AGI 闪避 = AGI/(AGI+敌命) 饱和族，Lv99 全押 +38 只挪个位数 %），玩家看不到明确回报，与"不费脑、有方向感"相抵；③"近战硬、远程滑"是 12 职业牌面，倾向点染指"滑" = 面板营销贬值。

> **倾向点三类契约（#11 讨论结论）**：
> 1. **纯增量、只加不改**：`属性 = 起始 + (等级−1)×(1+核系数+家族轴) + 天赋 + 倾向点`——倾向点 = 独立末项，不改曲线斜率、不从总池划拨、不与曲线换乘；职业曲线 = 不可谈判骨架（Lv99 曲线项 ≈140~160 点 vs 倾向点上限 38 点，翻不了）。
> 2. **绝对增量与职业无关**：+2/5级 直接入面，无职业乘数——Lv99 全押 = +38 点（任意英雄、任意倾向同价）。
> 3. **防御形状不可被倾向点更改**：Lv99 下远程（脉冲）全押偏肉 VIT = 148 ≈ 近战（铁砧）不偏肉 VIT 159 的 **93%**——可接近、不可翻转；防御形状只能由家族轴（+0.5/级×98）决定。

> **五倾向权重表（#11 定稿 · 全押单体 + 均衡均摊）**：+2/5级 的 100% 落单属性——方向档直接、面板可辨；不设拆分（1+1 与均衡档中间态重叠、语义污染、"偏攻为何给 VIT"悖论、方向感减半）；自由分配池否决（需分配记录+洗点 UI+"不费脑"红线）。均衡档 = 池内四属性各 25%。
> - 偏攻 → STR 100%｜偏肉 → VIT 100%｜偏速 → DEX 100%｜偏智 → INT 100%｜均衡 → STR/VIT/DEX/INT 各 25%（AGI 一律 0%）
> - 均衡档计数：0.5 点 × 4 属性 = 2 点/5级 对账成立；底层浮点、显示向上取整（与全项目口径一致）；Lv99 均衡各 +9.5。
> - 微调带落点：全押 Lv99 单属性 +38 ≈ 职业成长 25%（近战 VIT 基座等效 +26.7%、远程 VIT 基座等效 +40%）——"微调有存在感、翻不了曲线"边界。
- **职业成长曲线**为属性加成基准（见 §3.4 职业表）：核属性额外成长，系数暂定（单核 +0.4/级、双核各 +0.3/级）。
- **家族轴（显性）**：近战家族 VIT 额外 +0.5/级、远程家族 AGI 额外 +0.5/级（暂定，100 级差约 50 点，体感"近战硬、远程滑"）；只加不减。台面呈现：面板属性数字差异 + 职业页「家族倾向：坚实体魄 / 灵巧身法」。
- **属性公式（#3 口径 · 唯一账本）**：`属性 = 起始 + (等级−1) × (1 + 核系数 + 家族轴) + 天赋`——Lv1 = 起始属性（出生面板语义）；所有属性展示/推算由此推导，表见 §3.5（脚本 `game/scripts/gen-hero-stats.mjs` 从 `heroStats()` 打印，文档 = 打印件）。

### 3.3 英雄等级与天赋（v0.3 修订，替代原"稀有度定上限"）

## 4. 战斗与远征数值

### 4.1 战斗公式（小队自动对撞）

```
命中率   = min(100%, max(5%, 攻击值 / (攻击值 + 敌方闪避值)))    （物理桶/法术桶各算各）
物理攻击值 = DEX×10 + STR×5        （力量侧职；智慧侧职此桶只有 DEX×10；纯敏两桶都只 DEX×10，但 DEX 自身最高）
法术攻击值 = DEX×10 + INT×5        （智慧侧职；力量侧职此桶只有 DEX×10）
英勇攻击值・桥位（#12 同批定） = 主属性×5 × 0.7（=×3.5，与闪避 70/30 成对；力敏物主/敏智法主/力智双给）
闪避值   = AGI×10，按落位分桶（纯力 物100/法0、纯智 0/100、纯敏 50/50、桥位 70/30 暂定——SYSTEMS §2.1）
英雄伤害 = 武器伤害区间 × (1 + STR/100) × (1 + Σ增伤%) × 暴击修正   （命中是独立 roll：未命中直接 0 伤，非伤害乘区——#12 引擎契约）
攻速     = 武器 BPS × (1 + DEX/100 + Σ攻速词缀%)   （次/秒；与 STR/100 同形同系数——三核伤害轴同构，INT 法伤 M2 对齐）
减伤     = 1 - K_甲/(K_甲 + 总护甲)               （K_甲=300：护甲300≈减伤50% 转折锚；装备端·随 iLv 膨胀）
抗性率   = (1 - K_抗/(K_抗 + VIT)) × 100%      （K_抗=300，主属性端：无装备膨胀源，仅 VIT+天赋/词缀百分点；硬上限 75%）
敌方伤害 = 敌方基础伤害 × (1 - 减伤) × (1 - 抗性率)  （两端分层共存：属性端抗性率 × 装备端护甲减伤，SYSTEMS §6）
```

> **命中契约（#3 Q5 定稿 · 封底不封顶）**：单侧截断 `min(100%, max(5%, …))`——**5% 地板**=无敌锁/戏剧性保留/对冲脸黑（期望承伤永远＞0，无需"狂暴计时器"补丁）；**取消 95% 天花板**=进攻方碾压低级场景 5% 落空纯属折磨（挂机"碾压低级图"是核心能力幻想，应 100% 顺滑）；附赠：敌闪避=0 → 命中率 100%，无"D=0 特例"。
> **敌方闪避系数化**（不随等级漂移）：敌方闪避值 = 分档系数 × 同级标准攻击值 ÷ 19（÷19 = 同级白怪命中 95% 锚点的数学形式：命中 95% ⇔ 闪避值:攻击值 = 1:19——标准攻击值 = 同级纯敏基准 DEX×10：Lv1≈120 → Lv50≈806 → Lv90≈1366）；命中率由"怪物分档"决定与等级无关——分档：白怪 ×1 / 精英 ×3 / 头目 ×8 / 传奇 ×15（暂定）→ 同级锚点 95% / 86% / 70% / 56%。**#12 已接线：引擎 `standardAttackValue()/enemyDodgeValue()/hitChance()`（expedition.js），rng 消耗序列契约 Q4（命中 roll → 伤害 roll）；region 分档 `monster.dodgeTiers` 落数据表。**
> 越级体感：Lv80 打 Lv10 图 → 攻击值 1226 vs 敌闪 6 → 100% 必中；Lv1 打 Lv90 白怪 ≈62%——miss 是越级阻力的**第二载体**（主闸仍是伤害/护甲）。

> **暴击契约（#3 Q4 定稿 · M2 接线时不可再改）**：
> - **判定次序**：命中判定 → 暴击判定 → 武器伤害掷骰（rng 纯函数步进，roll 次序 = 战斗契约——改了即换 rng 消耗序列，确定性全破）。
> - **暴击率 = 5%（基础，PoE 对齐）+ Σ装备词缀**，上限 95%（与命中率截断同款）。
> - **暴击修正 = 独立乘区**，不吃 Σ增伤%；**暴伤基线 = 2×（+100%）**——"伤害翻倍"是可读爽点，且每点暴击率 EV 恰好 1:1（期望乘子 = 1 + 暴击率 × (暴伤倍率 − 1)，战力评估用）。
> - **适用矩阵**：物理直击 / 常规元素直击 / 奥术 ✓；毒 DoT ✗；真伤 ✗；**怪物侧：无暴击**（挂机里敌方暴击=纯负面噪声——待确认）。
> - 1.5× 基线否决：暴击率词缀 EV 值过贵坠成死词缀（5-6%@1.5× 等价 0.75% 增伤，"15 倍"死区间）；2× 下暴击率词缀可按 1:1 定价。

> **Σ增伤桶规则（#3 Q3 定稿）**：伤害类%**同桶加算**（"近战伤害 15%"+"钝器伤害 30%" → +45%）；不同来源桶（STR 桶 / 增伤桶 / 攻速桶）**乘法**；词缀括号预埋 `×(1 + DEX/100 + Σ攻速词缀%)`——M3 词缀直接有家。
> **DEX 主属性的定位**：攻速与攻击值（命中管线输入，同维双用，§3.1/§4.1）——对称律下终局弓 1.6×(1+DEX/100) 可达 ≈4 次/秒（250ms/击）；若未来读取感太刷，走软上限（如 ≤3 设定值），**不以压缩线性系数为代价**——系数是敏核 100 级的身份载体。

### 5.3 防具词缀池（示例 · 按槽位切换池）

## 9. 离线结算（确定性公式）

```
启动时：
  离线时长 = now - lastSavedAt
  若 > 1 分钟：
    有效产出 = 离线时长 × 在线每秒产出 × 离线效率系数(60%)
    经验    = 离线时长 × 在线每秒经验 × 0.6
    单次结算上限 = 24 小时（超出丢弃）
  叠加：英雄自主行动事件 1~3 条（只给少量额外奖励+叙事汇报，防止数值爆炸）
```

- 上限保护：24h 封顶 + 击杀数/开箱数封顶，避免一次结算卡死浏览器。
- 离线 60% < 在线 100%：鼓励在线，不惩罚离线（配合"摸鱼"形态：挂着就行）。
