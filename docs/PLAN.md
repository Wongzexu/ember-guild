| 部分 | 现状 | 归属 |
|------|------|------|

## 2. 每步的"做对了"标准

| 步骤 | 做对的标准（验收） |
|------|-------------------|
| 1 核心体验 | 能用一句话说清"玩这个游戏的感觉"，且你自己认可 |
| 2 题材 | 提到题材你能兴奋地多说几句，而不是"都行" |
| 3 核心循环 | 一张循环图，里面每一步都能对应回第 1 步的体验 |
| 4 特色钩子 | 说给没玩过的人听，对方会说"这有点意思" |
| 5 系统清单 | 每个系统都能说清"它服务哪个体验" |
| 6 定稿 | GDD/NUMBERS 更新完成，读起来无占位 |
| 7 技术复核 | ARCHITECTURE 与方向不再矛盾 |
| 8 定稿 | DECISIONS 全转 ✅；你亲口说"方向定了" |
