# 体系全览（SYSTEMS）· v0.10（含 v0.7 几何定位 + v0.8~v0.10 三直径/极×层）

> 战斗+成长体系的唯一权威骨架：**两个色环（几何定位）· 一条极性轴（两极对称）· 一个职业定位器**。
> 本文只定结构，数字一律占位（M2 战斗公式定稿时配套）。
> 关联：GDD §0（引用本文件）、NUMBERS §3~§4（数值细节）、DECISIONS（决策记录）。
> 几何定位原则：所有体系在大脑中按**圆盘/坐标**构思，规则随位置可推导。

---

## 0. 总览

```
两个色环（同构但独立、互不映射）
  属性环：三原色 力/敏/智 → 3 单 + 3 双 = 六核
  元素环：三原色 火/雷/冰 → 3 单 + 3 双 = 6 型

一条极性轴（贯穿伤害/命闪/防御，处处对称）
  物理 ↔ 法术

一个定位器
  职业 = 六核 × 近/远武器家族 = 12 职；与元素无关
```

---

## 1. 属性盘（色环 · 圆盘）

**三原色摆位（几何定位）**

```
              力（正上 12 点）
            ◤          ◥
     │ 力量侧半区 │    │ 敏捷直径：过敏点+圆心
    ◣             刺    ← 把盘切成两个半区
    敏（左下 ≈7:30）  智（右下 ≈4:30）
              智慧侧半区
```

- **三原色**：力（正上）、敏（左下）、智（右下）。
- **六核** = 3 原色 + 3 混合色（复合核落在相邻原色之间的**弧中点**）：纯力/纯敏/纯智/力敏/敏智/力智。
- **职业落位**：12 职全走六核的盘上坐标 + 家族轴外置（VIT/AGI，见 NUMBERS §3.2）。
- 生存对：VIT（生命，独立轴）、AGI（灵巧，线状，见下节）——不出现在三原色扇区里，是盘外的坐标轴。

## 2. 坐标轴三直径：AGI 敏捷直径 / VIT 力量直径 / INT 智慧直径

### 2.1 AGI 灵巧 · 敏捷直径（命中/闪避转出规则）

- 从**敏捷点**画一条过圆心的直径 → 把盘分为两个半区：**力量侧**（含力）/ **智慧侧**（含智）。
- **命中和闪避是相生相对的对偶属性：同在一条轴上**——每半区承载该极的命中+闪避两力：
  - 力量侧 → 物理命中 & 物理闪避
  - 智慧侧 → 法术命中 & 法术闪避
  - 敏捷点（在轴上）→ 双命中 & 双闪避均衡
- 职业落位决定转出倾斜（哪边主、轴点双给）。

| 核 | 几何落位 | 半区 | 命中转出（细） | 闪避转出（细） |
|----|---------|------|------|------|
| 纯力 | 力点 | 力量侧 | 物理桶 = DEX×10 + STR×5；法术桶 = DEX×10 | 物 100 / 法 0 |
| 纯敏 | 敏点（在轴上） | 轴 | 两桶都 = DEX×10（但 DEX 自身最高） | 物 50 / 法 50 |
| 纯智 | 智点 | 智慧侧 | 法术桶 = DEX×10 + INT×5；物理桶 = DEX×10 | 物 0 / 法 100 |
| 桥位（力敏/敏智/力智） | 弧中点 | 半区/跨带 | 待定（M2 同批定比值——主属性×5 的折扣系数） | 物 70 / 法 30（暂定） |

> **转出机制（#3 Q5 定稿 · 可计算机制，非形容词）**：物理攻击值 = DEX×10 + STR×5；法术攻击值 = DEX×10 + INT×5；闪避值 = AGI×10 × 按上表分桶；命中率 = min(100%, max(5%, 攻击值/(攻击值+敌方闪避值)))——完整规格见 NUMBERS §4.1。
> 注：这是职业属性的**成长曲线问题**（不是装备问题）——盘上落位 → 属性成长形状 → 命/闪分配。命中力来源（DEX 基础命中修正等）与公式 M2 定。

### 2.2 VIT 体质 · 力量直径（抗性转出规则）

- 从**力量点**画一条过圆心的直径（纵轴）→ 把盘分为**敏捷侧**（含敏）/ **智慧侧**（含智）。
- VIT 出**物理抗性 / 法术抗性**（属性端减免），转出随职业落位：半区决定主营的一侧。
- 力点在轴上 → **双抗都给**（纯力/力敏/力智双抗倾向）。

| 核 | 几何落位 | 半区 | 抗性转出 |
|----|---------|------|---------|
| 纯力 | 力点（在轴上） | 轴 | 双抗均衡（微偏物？M2） |
| 纯敏 | 敏点 | 敏捷侧 | 物理抗性为主 |
| 纯智 | 智点 | 智慧侧 | 法术抗性为主 |
| 力敏 | 弧中点 | 敏捷侧 | 物理抗性为主 |
| 敏智 | 弧中点 | 智慧侧 | 法术抗性为主 |
| 力智 | 弧中点（跨带） | 跨/带 | 双抗都加且多 |

- **属性端 vs 装备端**：VIT 出抗 = 人物属性端减免；护甲（物）/ 元素抗（色环）= 装备端减免（词缀/基底）。两端**不同来源、分层共存**；叠加方式（相乘/分段）M2 定。
- **抗性公式（#3 Q6 定稿 · 回答"是否与护甲同构"挂起项）**：`抗性率 = 1 − K_抗/(K_抗+VIT)`——**同构**（A/(A+B) 饱和族），与护甲 `1−K_甲/(K_甲+总护甲)` 数学同一族；K_抗=300（50% 转折锚，固定）vs K_甲=300（装备端，随 iLv 膨胀）；**75% = 硬上限**（封天赋/词缀百分点）；天赋/词缀百分点**全额线性**（边际属性递减、平坦加成不递减——Lv35 双抗+8% 不贬值）。
- **与 AGI 轴的红利（同族数学语言）**：AGI 闪避纲要 `AGI/(AGI+敌方命中)` 同为 A/(A+B) 饱和形——生存对两条轴数学归一。**锚点差异**：VIT 侧锚固定 300（曲线随等级衰减，保底减免）；AGI 侧锚 = 敌方命中（随内容涨，曲线被内容推着跑）→ "近战稳（保底减免）、远程赌（闪避衰减）"体感差异有了数学表述。
- **与 AGI 抛物线**：AGI 管闪避（概率层）、VIT 管抗性（减免层）——两轴交点 = 圆心，分别为盘上两个维度的原点。

### 2.3 INT 智力 · 智慧直径（法术转出规则 · PoE 灵感）

- 从**智慧点**画一条过圆心的直径 → 把盘分为**力量侧**（含力）/ **敏捷侧**（含敏）。
- INT 出**法术伤害加成** + 法术转出对：**直击 vs 特效（持续）**——
  - **力量侧**：法术**直击伤害**高（元素命中伤）
  - **敏捷侧**：法术**特效/持续伤害**高（灼烧/感电/缓滞/毒等 DoT 与状态类）
  - **智点（在轴上）**：双给——直击与特效均衡
- 机制因果：元素伤害会产生特效（PoE 式：法术元素伤害挂状态/持续）；特效类吃哪套加成由落位决定。
- 与 VIT/AGI 轴对称：三轴分别为——AGI 敏捷直径（闪避概率层）/ VIT 力量直径（抗性减免层）/ INT 智慧直径（法术直击↔特效）。

| 核 | 几何落位 | 半区 | 法术转出 |
|----|---------|------|---------|
| 纯力 | 力点 | 力量侧 | 直击为主 |
| 纯敏 | 敏点 | 敏捷侧 | 特效/持续为主 |
| 纯智 | 智点（在轴上） | 轴 | 双给均衡 |
| 力敏 | 弧中点 | 力量侧 | 直击为主 |
| 敏智 | 弧中点 | 敏捷侧 | 特效/持续为主 |
| 力智 | 弧中点（跨带） | 跨/带 | 双给且多 |

## 3. 元素环（色环 · 圆环）

- **一层 · 常规主元素**（数值层）：3 原色 火/雷/冰 + 3 混合（火雷/火冰/雷冰，混合 = 相邻混合色）= 6 型。
  - 吃 INT 元素加成 + 对应元素词缀。
  - 与属性环**只镜像结构、不镜像关联**：火雷≠力敏，两环互不映射。
  - 双元素组合名：暂占位（火雷/火冰/雷冰）。
- **二层 · 特殊能力元素**（机制位）：毒（DoT + debuff，只吃毒词条）/ 奥术（"无属性法力伤"，吃 INT，不吃元素抗性/易伤，只吃法术增减）。
- 元素与职业**无关**：职业表不设元素主色（NUMBERS §3.4），元素经装备词缀/技能进入战斗。

## 4. 伤害（两极 · 两维：极 × 层）

**第一层 · 直接层**（命中伤的产物）

| 极 | 基准 | 本极真伤 |
|----|------|---------|
| 物理极 | 物理基准（武器基准伤害，护甲减伤基准线） | 物理真伤（如流血/割裂：无视护甲） |
| 法术极 | 元素基准（元素环：一层 6 型 + 二层毒/奥术） | 法术真伤（元素真伤：无视元素抗性，如湮灭炮） |

**第二层 · 衍生层**（由直击派生的特效/持续伤害）

- 直击命中 → 触发**特效/持续伤害**（衍生物）：灼烧（火）/感电（雷）/缓滞（冰）/毒（DoT）/割裂（流血）等。
- 吃「特效/持续」套加成（§2.3 敏侧 INT），不吃直击套——两套加成按落位分配。
- **真伤与层级正交**：真伤 = 极内"无视减免"属性，可直接/衍生任意形态生效（流血 = 物理真伤 × 衍生：每跳无视护甲）。

- 维度关系：伤害 = **极**（物理/法术）× **层**（直接/衍生）× 真伤（无视减免属性位）。

## 5. 命中 / 闪避（两极 · 两套独立对抗）

```
物理攻击：物理命中 vs 物理闪避
法术攻击：法术命中 vs 法术闪避
（两套独立的"命中力 vs 闪避力"对抗，按极分账）
```

- 闪避来源：AGI 转出（随职业落位，§2.1）+ 家族轴 AGI 上浮（远程，NUMBERS §3.2）；命中与闪避**同轴对偶**（§2.1）。
- 待定：闪避对真伤 / 衍生 DoT（流血、中毒）是否生效（M2）。

## 6. 防御（两极对称 · 属性端 / 装备端分层）

| 来源端 | 层 | 物理极 | 法术极 |
|--------|----|--------|--------|
| **属性端**（人物成长） | 减免层·抗性 | 物理抗性（VIT 转出，§2.2） | 法术抗性（VIT 转出，§2.2） |
| 属性端 | 规避层 | 物理闪避（AGI 转出，§2.1） | 法术闪避（AGI 转出，§2.1） |
| **装备端**（词缀/基底） | 减免层 | 护甲（减伤公式已成） | **元素抗——按色环细分**：火抗 / 雷抗 / 冰抗（+ 双元素抗细则 M2） |
| 装备端 | 特殊（推导型，不占独立词缀位） | — | **毒抗 = 全部元素抗的「平均」**；**奥抗 = 全部元素抗的「总加」**（上限/曲线 M2） |

- 属性端（VIT/AGI 转出）与装备端（护甲/元素抗）**不同来源、分层共存**；合算方式（相乘/分段叠加）M2 定。
- 真伤天然穿透两端减免（§4 定义保证）。
- 双元素抗（火雷等混合型）推导细则：M2 配套。

## 7. 公式骨架（占位；M2 定稿）

```
命中率   = 攻击力/(攻击力 + 敌方闪避)        （两套：物理/法术各算，需按极拆）
闪避率   = AGI/(AGI + 敌方命中)             （两套，AGI 转出随落位，§2.1）
物理伤害 = 武器命中区间 × (1+STR/100) × (1+Σ增伤%) × 命中修正
减伤     = 1 - 300/(300 + 总护甲)           （护甲=装备端；元素抗同理）
抗性     = VIT 转出（物抗/法抗，随落位 §2.2）——属性端；装备端×属性端合算 M2 定
```
