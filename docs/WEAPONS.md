# 武器系统总览（WEAPONS）· v1.0

> 武器系统**机制正文唯一入口**（PoE 式·已简化）。数字细则表（基底阶梯/词缀数值/通货掉率）留在 NUMBERS §5~§6，此处只引用不复制。圆环图见 [wiki/weapon-ring.html](wiki/weapon-ring.html)（亦可作维基站入口 [wiki/index.html](wiki/index.html)）。决策沿革 DECISIONS v0.11~v0.13。

## 1. 设计原则

PoE 简化版：**基底 + 前缀/后缀词缀 + Tier + 稀有度 + 通货锻造**；不做连线、技能宝石、打孔符文（灵珠列为后期可选）。
核心铁律：**武器决定流派**（换装即换定位）；**基底谁都能用，职业仅是"顺手偏好"，不锁死**（规划按 12 职业映射，落位按通用基底）。

## 3. 武器圆环（六核环）

```
        力（顶）
  力敏（桥）━━ 力智（桥）
    敏  ◆ 通吃 ◆  智
    敏智（桥）
```

- 核归属：**力**=单手锤·大锤·大剑｜**敏**=短刀·弓·弩｜**智**=短杖·法器
- **桥（双形态·跨近/远族）**：力敏=矛（近战⇄投掷）· 敏智=匕首（近战⇄飞掷）· 力智=长杖（远程⇄扫击）——词缀转换，天赋判定走基准族
- **通吃（不属任一核）**：单手剑（力=剑气·远程物理 / 敏=快击·近战速 / 智=法刃·近战法术——三倾向即三形态）+ 盾=副手大类（物盾/轻盾/符盾）
- **缺口弥补**（v0.12）：纯力远（弹射）= 矛（投掷）＋单手剑（剑气）；纯智近（结晶）= 单手剑（法刃）＋匕首（近战）——12 职业零空位
- 可视化：见 [wiki/weapon-ring.html](wiki/weapon-ring.html)

## 4. 形态（不拆类型 · 参数带内变体）

- **弩** = 单类型，**轻/重为形态**：轻弩（极快·低伤）/ 重弩（慢·高伤）——形态定攻速/伤害
- **矛**（投掷）/ **匕首**（飞掷）/ **长杖**（扫击）= 桥位双形态，条件词缀显性文本（例："作为远程武器使用时，攻速/命中 +X%"）
- **盾** = 副手大类，三形态：物盾（力·免伤）/ 轻盾（敏·格挡）/ 符盾（智·施法增益）
- **单手剑** = 三倾向：剑气（力·远程）/ 快击（敏·近战速）/ 法刃（智·近战法术）

## 5. 单手/双手与副手

| 场景 | 规则 |
|------|------|
| 单手武器（锤/刀/杖/剑） | 副手 = **盾**（形态随属性倾向）⊕ **双持**（另一把单手武器） |
| 双手武器（锤/剑/矛/匕首/弓/弩/杖/法器） | 无副手，**占两槽** |

## 6. 词缀结构

| 槽 | 内容 | Tier |
|---|---|---|
| **前缀**（伤害向） | +物伤 / +元素伤 / 攻速 / 暴击 | I~III（数值区间见 NUMBERS §5.2） |
| **后缀**（属性/条件向） | +属性 / 命中 / 形态条件词缀（"作为远程武器使用时…"） | I~III |

- **稀有度 → 词缀数**：普通 0 / 稀有 1~2 / 史诗 3~4 / 传说 4~6 ＋ 1 条**独占触发词缀**（例："击败敌人时 5% 几率触发烧伤"）；最多 3 前 + 3 后。
- **iLv 定天花板**：Tier 解锁门槛（III=1 / II=35 / I=65，NUMBERS §5.5）。
- **武器固有词缀（基底隐性）**与词缀池分离（铜锤 = 无词缀白装）。

## 8. 装备槽位（8 位 · v0.13 定案）

| 槽位 | 默认 | 备注 |
|------|------|------|
| 主手 | 武器（单手/双手占用） | 双手武器同时占主+副 |
| 副手 | 盾（物盾/轻盾/符盾）⊕ 双持 | 单手武器才有副手选单 |
| 头 / 身 / 手 / 脚 | 防具 4 | 各带各自词缀池（防具池通用） |
| 戒指 / 项链 | 饰品 2 | 词缀池最稀（"诱人词缀"优选位） |
