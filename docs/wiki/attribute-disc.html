属性盘 五维坐标 · 六核圆盘

本文介绍的是属性盘——游戏内五维属性的几何坐标盘。武器的分区落位见 武器圆环；结构镜像但内容无关的元素体系见 元素环。依据 SYSTEMS v0.10 整理。

属性盘
体系类型色环 · 圆盘坐标
三原色力 / 敏 / 智
六核3 原色 + 3 混合色混合核 = 相邻原色弧中点

数值细则NUMBERS §3~§4
决策沿革SYSTEMS v0.8~v0.10

1. 概述

所有体系在大脑中按圆盘 / 坐标构思，规则随位置可推导——这就是「几何定位法」。属性盘以此承载五维：三原色力 / 敏 / 智是盘上的色块，体质 VIT 与灵巧 AGI 是盘外的坐标轴。

属性盘 · 六核 + 三直径（虚线；赭红色为轴标签色，非属性色）

判读：力（顶）敏（左下）智（右下）｜混合核（弧中点）：力敏 · 敏智 · 力智 ｜ 三条虚线直径（借点引轴）：VIT 借力量直径（过力点·抗性）/ AGI 借敏捷直径（过敏点·命闪对偶）/ INT 自引智慧直径（过智点·法术分型） ｜ 圆心 = 两生存轴原点；VIT / AGI 不入扇区，是盘外的坐标轴。

十二职业 全部 走六核的盘上坐标，家族轴（近/远 / VIT / AGI）外置——详见 武器系统 与 NUMBERS §3.2。

3. 三条直径（转出规则）

三条直径均画过圆心，把盘切成两个半区。半区归属决定该属性的转出倾斜：轴上的点（原色点）双重给，半区内的点单边给。

3.0 术语澄清：点 · 直径 · 轴外

盘上有两套各管各个的东西：点（色位）回答「你是做什么的」——职业身份；直径回答「按哪个半区转出」——分型账。两者不是一回事：

属性色位（身份）直径（转出分型）一言以蔽之
INT 智力智核（智点）智慧直径 = 自家点引自家直径双重身份：法术既是身份，又要内部直击↔特效分型
VIT 体质无（接受端）转出分型借用过力点的「力量直径」单重身份：只有减免数值 + 借半区定倾斜
AGI 灵巧无（接受端）转出分型借用过敏点的「敏捷直径」单重身份：同上

命名陷阱：三根直径不是「XX 属性的直径」，而是「从某原色点引出的直径」——力量直径过力点（STR）、敏捷直径过敏点（DEX）、智慧直径过智点（INT）。VIT / AGI 是「借邻家点的直径」切半区；INT 是唯一「自点自引」的：法术侧要切的两半（力量侧/敏捷侧）恰是它自己要分账的两端，拆不开。

VIT / AGI 为什么没有色位：它们是接受端（挨打时怎么减免），不定义「你是什么职业」——人人都有体质与灵巧，只需要大小即可；转出倾斜由职业落位（力侧/智侧…）代为决定。这就是「轴外坐标」的准确含义：盘上无身份，盘外有数值。

3.1 AGI 敏捷直径（命中 / 闪避对偶）

从敏捷点过圆心画直径 → 分力量侧（含力）/ 智慧侧（含智）。命中与闪避是相生相对的对偶属性、同在一条轴上：每半区承载该极的命中 + 闪避两力。

核几何落位命中转出（细）闪避转出（细）
纯力力点物理桶 = DEX×10 + STR×5；法术桶 = DEX×10物 100 / 法 0
纯敏敏点（在轴上）两桶都 = DEX×10（但 DEX 自身最高）物 50 / 法 50
纯智智点法术桶 = DEX×10 + INT×5；物理桶 = DEX×10物 0 / 法 100
桥位（力敏/敏智/力智）弧中点待定（M2 同批定比值——主属性×5 的折扣系数）物 70 / 法 30（暂定）

转出机制（#3 Q5 定稿）：物理攻击值 = DEX×10 + STR×5；法术攻击值 = DEX×10 + INT×5；闪避值 = AGI×10 按上表分桶；命中率 = min(100%, max(5%, 攻击值 / (攻击值 + 敌方闪避值)))。完整规格见 NUMBERS §4.1。

3.2 VIT 力量直径（抗性转出）

从力量点过圆心画直径（纵轴）→ 分敏捷侧（含敏）/ 智慧侧（含智）。VIT 出物理抗性 / 法术抗性（属性端减免），力点在轴上 → 双抗都给。

核几何落位抗性转出
纯力力点（在轴上）双抗均衡（微偏物？M2）
纯敏敏点物理抗性为主
纯智智点法术抗性为主
力敏弧中点物理抗性为主
敏智弧中点法术抗性为主
力智弧中点（跨带）双抗都加且多

抗性公式（#3 Q6 定稿）：抗性率 = 1 − K_抗/(K_抗+VIT)，与护甲 1−K_甲/(K_甲+总护甲) 数学同构（A/(A+B) 饱和族）；K_抗 = 300（50% 转折锚，固定）；75% = 硬上限（封天赋/词缀百分点）；天赋/词缀百分点全额线性（不递减）。

与 AGI 轴的同族数学：AGI 闪避纲要 AGI/(AGI+敌方命中) 同为 A/(A+B) 饱和形——生存对两条轴归一。锚点差异：VIT 侧固定（保底减免，近战稳）；AGI 侧锚 = 敌方命中（随内容涨，闪避衰减，远程赌）。

3.3 INT 智慧直径（法术直击 ↔ 特效）

从智慧点过圆心画直径 → 分力量侧（含力）/ 敏捷侧（含敏）。INT 出法术伤害加成 + 法术转出对：直击 vs 特效（持续）——力量侧直击高，敏捷侧持续/状态高，智点（在轴上）双给。

核几何落位法术转出
纯力力点直击为主
纯敏敏点特效/持续为主
纯智智点（在轴上）双给均衡
力敏弧中点直击为主
敏智弧中点特效/持续为主
力智弧中点（跨带）双给且多

机制因果：元素伤害会产生特效（PoE 式：法术元素伤害挂状态/持续）；特效类吃哪套加成由落位决定。三轴分别为——AGI（闪避概率层）/ VIT（抗性减免层）/ INT（法术直击↔特效），交点 = 圆心 = 两个维度的原点。

4. 轴外坐标（家族轴）

VIT（体质）与 AGI（灵巧）作为生存对出现在盘外坐标轴上：VIT 管生命与抗性（减免层），AGI 管闪避（概率层）。它们不具备色位——不定义职业身份、只有数值大小，其转出倾斜由职业落位代答（借直径切半区，见 术语澄清）。与命中/闪避、护甲的关系见 战斗体系。
