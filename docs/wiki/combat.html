战斗体系 两极 · 双维 · 分层防御

本文介绍的是战斗体系——伤害、命中/闪避、防御三大块的结构。属性转出规则见 属性盘 §3；法术极的元素基准见 元素环。依据 SYSTEMS v0.10 §4~§8 整理。

战斗体系
伤害维度极（物理/法术）× 层（直接/衍生）× 真伤（无视减免）
命闪对抗两套独立物理命中 vs 物理闪避 · 法术命中 vs 法术闪避
防御分层属性端（VIT/AGI 转出）+ 装备端（护甲 / 元素抗）
公式族A/(A+B) 饱和族护甲/抗性/命中/闪避同构
定稿状态骨架定稿 · 数值 M2 配套
数值细则NUMBERS §4

1. 伤害（两极 · 两维：极 × 层）

伤害的第一个维度是极（物理 / 法术），第二个维度是层（直接层 / 衍生层）；真伤是「无视减免」的独立属性位，可与任意极、任意层正交生效。

第一层 · 直接层（命中伤的产物）

极基准本极真伤
物理极物理基准（武器基准伤害 → 护甲减伤基准线）物理真伤（如流血/割裂：无视护甲）
法术极元素基准（元素环：一层 6 型 + 二层毒/奥术）法术真伤（元素真伤：无视元素抗性，如湮灭炮）

第二层 · 衍生层（由直击派生的特效/持续伤害）

直击命中 → 触发特效/持续伤害：灼烧（火）/ 感电（雷）/ 缓滞（冰）/ 毒（DoT）/ 割裂（流血）等。衍生物吃「特效/持续」套加成、不吃直击套——两套加成按落位分配（见 INT 智慧直径）。

真伤与层级正交：真伤 = 极内「无视减免」属性，可直接/衍生任意形态生效——流血 = 物理真伤 × 衍生：每跳无视护甲。

2. 命中 / 闪避（两极 · 两套独立对抗）

物理攻击：物理命中 vs 物理闪避
法术攻击：法术命中 vs 法术闪避
（两套独立的「命中力 vs 闪避力」对抗，按极分账）
  • 闪避来源：AGI 转出（随职业落位，属性盘 §3.1）+ 家族轴 AGI 上浮（远程，NUMBERS §3.2）。
  • 命中与闪避是同轴对偶属性：同在 AGI 直径上，每半区承载该极的两力。
  • 待定：闪避对真伤 / 衍生 DoT（流血、中毒）是否生效（M2）。

3. 防御（两极对称 · 属性端 / 装备端分层）

来源端层物理极法术极
属性端（人物成长）减免层·抗性物理抗性（VIT 转出）法术抗性（VIT 转出）
规避层物理闪避（AGI 转出）法术闪避（AGI 转出）
装备端（词缀/基底）减免层护甲（减伤公式已成）元素抗——按色环细分：火抗 / 雷抗 / 冰抗（双元素混合抗细则 M2）
特殊（推导型，不占独立词缀位）—毒抗 = 全部元素抗的平均；奥抗 = 全部元素抗的总加（上限/曲线 M2）
  • 属性端（VIT/AGI 转出）与装备端（护甲/元素抗）不同来源、分层共存；合算方式（相乘/分段叠加）M2 定。
  • 真伤天然穿透两端减免（§1 定义保证）。

4. 公式骨架（占位 · M2 定稿）

命中率   = 攻击力/(攻击力 + 敌方闪避)          （两套：物理/法术各算，需按极拆）
闪避率   = AGI/(AGI + 敌方命中)               （两套，AGI 转出随落位，§2.1）
物理伤害 = 武器命中区间 × (1+STR/100) × (1+Σ增伤%) × 命中修正
减伤     = 1 - 300/(300 + 总护甲)             （护甲=装备端；元素抗同理）
抗性     = VIT 转出（物抗/法抗，随落位 §2.2）——属性端；装备端×属性端合算 M2 定

5. 待细节点（M2 战斗公式定稿配套）

  • 元素抗曲线公式（是否与护甲同构、同软上限）。
  • 双元素（混合色）抗性推导；毒抗「平均」、奥抗「总加」的具体数值口径与上限。
  • 属性端（VIT 抗性）与装备端（护甲/元素抗）的合算公式；抗性软上限。
  • 闪避对真伤/DoT 是否生效；命中/闪避按极拆后的数值校准。

占位声明：§4 公式骨架为结构性占位，M2 定稿前不承诺式样与数值。
