元素环 色环 · 六型双元素体系

本文介绍的是元素环——法术伤害的元素类型环。与 属性盘 结构同构但互不映射；元素如何参与战斗/防御见 战斗体系。依据 SYSTEMS v0.10 整理。

元素环
体系类型色环 · 圆环
一层 · 主元素火 雷 冰+ 三混合：火雷 / 火冰 / 雷冰 = 6 型
二层 · 能力元素毒 · 奥术机制位，不占主元素格
与属性盘只镜像结构，不镜像关联火雷 ≠ 力敏
与职业无关元素经装备词缀/技能进入战斗
数值细则NUMBERS §3.4
决策沿革SYSTEMS v0.10

1. 概述

元素环是法术侧的颜色编码，与属性盘是两张同构但独立的色环：三原色（火/雷/冰）→ 三混合（弧中点），结构完全一样，内容各不相干。元素与职业无关——职业表不设元素主色，元素只能经装备词缀或技能进入战斗。

元素环 · 一层六型（外环带）+ 二层能力元素（中心圈）

判读：火（顶）雷（右下）冰（左下）｜混合型（弧中点）：火雷 · 雷冰 · 火冰 ｜ 虚线内圈 = 二层机制位：毒（DoT+debuff，只吃毒词条）· 奥术（无属性法力伤，不想吃元素抗性/易伤）。

与属性环只镜像结构、不镜像关联：元素环的混合型（火雷）对应的是结构上的「弧中点」，内容上与属性盘的力敏核没有任何对应关系。

3. 二层 · 特殊能力元素（机制位）

  • 毒：DoT + debuff 体系，只吃毒词条——不参与元素环主元素的加成分账。
  • 奥术：「无属性法力伤」，吃 INT，不吃元素抗性 / 易伤，只吃法术增减——真伤系法术的典型出口。

4. 与战斗体系的接线

  • 伤害侧：元素环是法术极的「基准」来源之一（数值层）；特效类（灼烧/感电/缓滞/毒）挂在一层的元素类型上，吃INT 直径的「特效/持续」套加成。
  • 防御侧：元素抗（装备端减免）按色环细分——火抗 / 雷抗 / 冰抗；双元素混合抗性细则 M2。两条推导型抗性：毒抗 = 全部元素抗的平均；奥抗 = 全部元素抗的总加（上限/曲线 M2）。
  • 真伤出口：元素真伤（无视元素抗，如湮灭炮）——见 战斗体系 §1。
