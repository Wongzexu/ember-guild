英雄系统 无稀有度 · 十二职业

本文介绍的是英雄系统——英雄的构成、成长与定位。五维与职业落位见 属性盘；武器与装备见 武器系统。依据 HEROES v1.0 整理。

1. 英雄构成

英雄 = 名字 + 职业 + 等级 + 性格/背景。没有稀有度——稀有度只属于装备（PoE 原生形态，DECISIONS v0.3）。英雄的「贵贱」由关卡与故事定义，不由档位定义。

2. 等级

  • 上限 100（正常途径）；特殊途径（世界事件/传奇内容）可突破 100。
  • 成长曲线保留（RS：前期快、后期慢）；获取时的初始等级差异承担原「稀有度」的语义——差异在起跑线，不在天花板。
  • 所有英雄都可无限成长。

3. 职业（12 职业 · 六核 × 近/远）

  • 12 职业 = 六核（纯力/纯敏/纯智/力敏/敏智/力智）× 近/远武器家族（NUMBERS §3.4 表）。
  • 职业决定属性成长曲线 + 武器条件天赋；同一核的近/远职业共享成长，差异在家族轴与天赋。
  • 职业与元素无关——元素偏向只在元素体系内部（见 元素环）。

4. 家族轴（显性）

近战职业 VIT 额外成长、远程职业 AGI 额外成长（+0.5/级 · 暂定）——面板可见、职业描述点明（「家族倾向：坚实体魄 / 灵巧身法」）。家族轴独立于六核，是属性盘上的轴外坐标。

5. 属性（五维）

五维 = 三核伤害轴（力量 / 敏捷 / 智力）+ 生存对（体质 / 灵巧）（NUMBERS §3.1 序号 = STR / DEX / INT / VIT / AGI）。职业曲线 + 家族轴为基准，玩家策略倾向（偏攻/偏肉/偏速/偏智/均衡）做权重微调——不费脑，适合挂机。

6. 天赋（被动词条 · Torchlight 式）

随等级达标解锁词条（例：艾格雷姆 Lv.5 STR+5），自动生效、无需手动加点；词条条件 = 近/远武器家族 + 通用垫底（NUMBERS §3.3/§3.4）。

7. 装备定型（武器决定流派）

  • 近战武器（大锤/短刀/大剑/矛/匕首…）→ 物理近战向；法术武器（短杖/长杖/法器）→ 施法向；弓弩 → 远程速攻向。
  • 换装备即换定位（PoE 式自由）；天赋对武器家族取条件，跨族换装只弱化不报废。
  • 武器 12 类清单/圆环见 武器圆环 与 武器系统。

8. 性格与背景（人设引擎）

每个英雄有性格/口头禅/背景故事 → 喂给「离线自主行动」和「编年史」，让英雄是「人」不是「数值」。模板基调（首英雄定调）：守护者 · 责任在心——温和、手粗、有担当；厌战不是怯懦，是看够了；二次召集者，无大义口号——「这炉火，总得有人守着。」

8.1 首英雄卡 · 艾格雷姆（铁砧 / 纯力近战）

首英雄人设已定调：守护者 · 责任在心。「这炉火，总得有人守着。」——完整英雄卡（性格/口头禅/叙事触点/数据条）见 英雄图鉴。

9. 招募

酒馆招募（消耗金币/线索）、远征掉落线索、高难委托慕名加入（保留）。
