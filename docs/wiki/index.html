《挂机远征》设定维基

欢迎来到设定维基。本维基收录《挂机远征》的规则与体系词条，是游戏设计文档的「词条化」呈现：每条目取自 GDD / SYSTEMS / WEAPONS 等规划文档的机制正文，保留结构与几何定位，数值细节仍归 NUMBERS 管辖。

关于本作

《挂机远征》是一款放置-远征式桌面策略游戏：组织一群英雄沿路线远征，战斗自动进行，玩家负责配装、转职与路线规划。核心构造逻辑是几何定位法——所有体系在大脑中按圆盘与坐标构思，规则随位置可推导。

当前开发期：M2 装备系统（战斗公式三件套已定稿）。本维基与规划文档同步增补。

阅读指引

  • 几何定位：属性盘与元素环是两张同构的色环——结构一致、内容无关（火雷 ≠ 力敏）。
  • 铁律：武器决定流派（换装即换定位）；基底谁都能用，职业仅是「顺手偏好」，不锁死。
  • 真伤穿透：伤害维度里「无视减免」是独立属性位，物理/法术极、直接/衍生层均可出现。
  • 占位声明：条目标注「占位 / M2 定稿」处为规划期待定项，不代表最终数值。
