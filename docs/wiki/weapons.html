武器系统 12 类 · 词缀 · 铸造

本文介绍的是武器系统整体机制。武器的属性分区与圆环图见 武器圆环；数字细则（基底阶梯/词缀数值/通货掉率）归 NUMBERS §5~§6。依据 WEAPONS v1.0 整理。

1. 设计原则

PoE 简化版：基底 + 前缀/后缀词缀 + Tier + 稀有度 + 通货锻造；不做连线、技能宝石、打孔符文（灵珠列为后期可选）。两条铁律：

  • 武器决定流派——换装即换定位。
  • 基底谁都能用，职业仅是「顺手偏好」，不锁死（规划按 12 职业映射，落位按通用基底）。

2. 武器类型（12 类 = 单手 4 + 双手 8）

类型持用手感带伤害侧副手选单
单手锤单手慢·重物理盾 ⊕ 双持
短刀单手极快·轻物理盾 ⊕ 双持
短杖单手快·低威·高频法术符盾 ⊕ 双持
单手剑单手中·中物理盾 ⊕ 双持
大锤双手极慢·极重物理无
大剑双手中·宽物理无
矛双手中·宽物理（投掷=词缀转换）无

弓双手极快·速射物理无
弩双手形态分档物理无

分类的几何依据（核归属 / 桥位 / 通吃）见 武器圆环。

3. 形态（不拆类型 · 参数带内变体）

载体形态
弩 = 单类型轻弩（极快·低伤）/ 重弩（慢·高伤）——形态定攻速/伤害，不拆类型
矛 / 匕首 / 长杖 = 桥位双形态投掷 / 飞掷 / 扫击——条件词缀显性文本（例：「作为远程武器使用时，攻速/命中 +X%」）
盾 = 副手大类三形态：物盾（力·免伤）/ 轻盾（敏·格挡）/ 符盾（智·施法增益）
单手剑 = 三倾向剑气（力·远程）/ 快击（敏·近战速）/ 法刃（智·近战法术）

4. 单手/双手与副手

场景规则
单手武器（锤/刀/杖/剑）副手 = 盾（形态随属性倾向）⊕ 双持（另一把单手武器）
双手武器（锤/剑/矛/匕首/弓/弩/杖/法器）无副手，占两槽

5. 词缀结构

槽内容Tier
前缀（伤害向）+物伤 / +元素伤 / 攻速 / 暴击I~III（数值区间见 NUMBERS §5.2）
后缀（属性/条件向）+属性 / 命中 / 形态条件词缀（「作为远程武器使用时…」）I~III
  • 稀有度 → 词缀数：普通 0 / 稀有 1~2 / 史诗 3~4 / 传说 4~6 ＋ 1 条独占触发词缀（例：「击败敌人时 5% 几率触发烧伤」）；最多 3 前 + 3 后。
  • iLv 定天花板：Tier 解锁门槛（III=1 / II=35 / I=65，NUMBERS §5.5）。
  • 固有词缀（基底隐性）与词缀池分离（铜锤 = 无词缀白装）。

6. 装备槽位（8 位 · v0.13 定案）

槽位默认备注
主手武器（单手/双手占用）双手武器同时占主+副
副手盾（物盾/轻盾/符盾）⊕ 双持单手武器才有副手选单
头 / 身 / 手 / 脚防具 4各带各自词缀池（防具池通用）
戒指 / 项链饰品 2词缀池最稀（「诱人词缀」优选位）

7. 铸造与通货

通货锻造（蜕变/改造/点金/重铸/混沌/崇高/神圣——掉率 NUMBERS §6）+ 铸造台保底（指定词缀必上、升级档、重 roll——对冲「纯随机劝退」，NUMBERS §5.6）。
